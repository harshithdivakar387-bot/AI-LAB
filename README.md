# Artificial Intelligence Lab

AI Lab practical notebooks for USN **1BM24CS112**.

| Week | File | Topic |
|---|---|---|
| 1 | `1BM24CS112_Week1_TicTacToe_VacuumAgents.ipynb` | Tic-Tac-Toe minimax and vacuum agents |
| 2 | `1BM24CS112_Week2_8Puzzle_DFS_IDS.ipynb` | 8-puzzle DFS and IDS |
| 3 | `1BM24CS112_Week3_8Puzzle_AStar.ipynb` | A* search with heuristics |
| 4 | `1BM24CS112_Week4_NQueens_HillClimbing.ipynb` | N-Queens hill climbing |
| 5 | `1BM24CS112_Week5_NQueens_SimulatedAnnealing.ipynb` | N-Queens simulated annealing |
| 6 | `1BM24CS112_Week6_PropositionalLogic_TruthTables.ipynb` | Propositional logic and truth tables |
| 7 | `1BM24CS112_Week7_FOL_Unification.ipynb` | First-order logic unification |
| 8 | `1BM24CS112_Week8_FOL_ForwardBackwardChaining.ipynb` | Forward and backward chaining |
| 9 | `1BM24CS112_Week9_FOL_Resolution.ipynb` | First-order logic resolution |

## Setup

Install Python 3.10 or newer, then run:

```bash
python -m pip install -r requirements.txt
jupyter lab
```

The existing IBM certificate file in this repository has been left untouched.
